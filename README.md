# Uber-customer-churn-analysis
An end-to-end Uber Customer Churn Analysis project leveraging Python for data cleaning and predictive modeling, SQL for querying and customer segmentation, and Power BI for interactive dashboards and churn visualization to support retention decision-making.
The project includes:
<br>
Data preprocessing and cleaning
<br>
Exploratory Data Analysis (EDA)
<br>
Feature engineering
<br>
Machine learning model development
<br>
Model evaluation and comparison
<br>
Dashboard visualization and business insights
<br>
Retention strategy recommendations
<br>
# Problem Statement
Customer churn is one of the major challenges faced by ride-booking and service-based businesses. Losing customers affects revenue, growth, and customer lifetime value. This project aims to predict customer churn using machine learning models and help businesses proactively identify at-risk customers and implement effective retention strategies.
# Objectives
Analyze customer behavior and churn patterns.
<br>
Identify factors influencing customer attrition.
<br>
Perform exploratory data analysis and feature engineering.
<br>
Build predictive machine learning models.
<br>
Compare model performance using evaluation metrics.
<br>
Identify at-risk customers.
<br>
Generate retention strategies and business insights.
<br>
Support data-driven decision-making.
<br>
